3D 프린팅용 STL 수리

모델을 놓으면 브라우저에서 바로 무료로 점검하고, 한 번 눌러 고칩니다. 겉모양은 그대로 두고 오류만 없앱니다. 구멍, 논매니폴드 엣지, 뒤집힌 면, 흩어진 조각, 노즐보다 얇은 부재까지 처리합니다.

무료 베타가입 없음24시간 뒤 파일 삭제

결함

    형상

      점검은 브라우저 안에서 합니다. 파일은 고치기를 누를 때만 올라갑니다.

      
    
      
    
      
  
      
  
      

  
      
    
      예시: 깨진 모델 수정 전과 후
      
    
      가운데 손잡이를 끌어 보세요. 같은 카메라, 같은 프레임입니다. 빨강은 열린·논매니폴드 엣지, 주황은 너무 얇아 출력되지 않는 부재입니다.
      
    
      
      
      
      BEFOREAFTER
      
      
    
      
  
      

  
      
    
      작동 방식
      
    
      1
      파일 놓기
      STL, OBJ, PLY, GLB, 3MF, OFF. 먼저 브라우저에서 구멍, 논매니폴드 엣지, 뒤집힌 면, 조각 수, 크기를 점검합니다.
      2
      고치기
      서버가 겉모양을 유지한 닫힌 솔리드로 다시 만들고, 노즐보다 얇은 부재를 정리한 뒤 결과를 검증합니다. 요청 문장을 쓰면 에이전트가 그대로 따릅니다.
      3
      확인하고 내려받기
      수정 전과 후를 나란히 3D로 돌려 보고, 출력 가능한 STL을 내려받습니다.
      
  
      

  
      
    
      출력을 망치는 오류와 처리 방법
      
    
      아래 오류가 있으면 슬라이서가 벽을 빠뜨리거나, 안팎을 바꿔 채우거나, 층을 건너뜁니다.
      
    
      01
      열린 엣지(구멍)
      무엇
      면 하나에만 붙은 엣지, 표면이 닫히지 않은 상태입니다.
      슬라이서에서
      안과 밖을 구분하지 못해 벽과 바닥이 빠집니다.
      printdoctor는
      닫힌 솔리드로 다시 만들고 주변 면을 따라 구멍을 메웁니다.
      02
      논매니폴드 엣지
      무엇
      면 셋 이상이 함께 쓰는 엣지. 용접되지 않은 CAD·건축 모델에서 흔합니다.
      슬라이서에서
      단면이 모호해져 층의 일부가 비어 나옵니다.
      printdoctor는
      겹치거나 맞닿은 조각을 하나의 솔리드, 하나의 깨끗한 표면으로 합칩니다.
      03
      뒤집힌 면
      무엇
      이웃한 면의 감김 방향이 서로 반대인 상태입니다.
      슬라이서에서
      모델 일부가 뒤집힌 것으로 처리됩니다.
      printdoctor는
      다시 만든 표면은 모두 바깥쪽으로 일관되게 향합니다.
      04
      넓이 0인 면
      무엇
      선이나 점으로 찌그러진 삼각형입니다.
      슬라이서에서
      슬라이서 경고, 미세한 틈, 불리언 실패의 원인이 됩니다.
      printdoctor는
      재구성 과정에서 없어집니다.
      05
      흩어진 조각
      무엇
      창틀, 패널, 글자처럼 따로 노는 수백 개의 조각입니다.
      슬라이서에서
      떠 있는 조각은 실처럼 나오거나 떨어지고, 겹친 곳은 벽이 두 겹이 됩니다.
      printdoctor는
      조각을 한 몸으로 합치고, 노즐보다 작은 부스러기는 버립니다.
      06
      노즐보다 얇은 부재
      무엇
      약 0.45 mm보다 가는 난간, 봉, 안테나입니다.
      슬라이서에서
      끊어진 실처럼 나오거나 아예 나오지 않습니다.
      printdoctor는
      찾아서 지우되, 표면에 붙은 글자·무늬 같은 양각은 남깁니다.
      
  
      

  
      

  
      
    
      printdoctor가 다른 점
      
    
      겉모양 유지
      결과를 원본과 비교해 편차(중앙값·95%)를 로그에 남깁니다.
      지저분한 내보내기에 강함
      용접 안 된 조각 수천 개짜리 SketchUp·Revit 모델, 게임·AI 생성 메시를 처리합니다.
      얇은 것을 구분
      출력이 안 되는 난간과 출력되는 글자·양각을 구분합니다.
      슬라이서 기준으로 검증
      열린·논매니폴드 엣지가 0이어야 출력 가능이라고 표시합니다.

      자주 묻는 질문
      
    
      STL을 온라인에서 어떻게 고치나요?
      위 도구에 파일을 놓으세요. 무료 점검으로 문제를 보여 주고, 고치기를 누르면 1분 안팎에 결과를 내려받을 수 있습니다.
      어떤 형식을 올릴 수 있나요?
      STL, OBJ, PLY, GLB/GLTF, 3MF, OFF를 50 MB까지 받습니다. 결과는 STL입니다.
      모양이 바뀌나요?
      25 cm 이하 모델은 약 0.2 mm 해상도로 표면을 다시 만들기 때문에 그보다 작은 디테일은 부드러워집니다. 원본과의 편차를 재서 보여 드립니다.
      요청 칸은 무엇인가요?
      요청을 쓰면 에이전트가 수리 단계를 정합니다. 예를 들어 난간은 지우고 글자는 남깁니다. 에이전트 처리는 하루 한도가 있고, 요청이 없으면 자동 수리가 돌아갑니다.
      무료인가요? 결과를 상업적으로 써도 되나요?
      베타는 광고로 운영되는 무료 서비스이고, 모델과 결과의 권리는 모두 이용자에게 있습니다.
      내 파일은 누가 보나요?
      처리하는 서버만 봅니다. 파일과 결과는 24시간 뒤 자동 삭제됩니다. 자세한 내용은 개인정보처리방침을 보세요.
      모델 단위가 cm나 인치예요
      배율을 넣으세요. cm는 10, 인치는 25.4를 넣으면 mm가 됩니다.
